# PromptMend documentation

These pages hold the details behind the [project README](../README.md): every option, every
setting and every edge case. Each page covers one question; start with the one that matches
what you want to do.

| Page | What you find there |
|------|---------------------|
| [Install](install.md) | Installing on macOS, Windows and Linux, verifying a download, updating, switching channel, uninstalling, and upgrading from older versions |
| [Usage](usage.md) | The triggers, when they fire, what they send, paste or clipboard output, the `-if-` form, your own triggers and the match files |
| [Commands](commands.md) | `improve` and its options, the scripting contract, every management command and the exit codes |
| [Configuration](configuration.md) | Where settings, keys and data live, how to change them, and the complete settings reference |
| [Profiles](profiles.md) | The built-in profiles, your own profiles and the persona |
| [Privacy](privacy.md) | What is sent and to whom, the data-protection gate, local-only mode, clipboard safety and the usage history |
| [Interface](interface.md) | The full-screen interface: tabs, Home, the Try tab and the keys |
| [Troubleshooting](troubleshooting.md) | `doctor` first, then each marker and symptom with its fix |
| [Benchmark](benchmark.md) | How the default models and prompt were chosen, and every result |
